# Security policy

Report vulnerabilities privately through the repository's GitHub Security
Advisories once the public repository is connected. Until that channel exists,
contact the repository owner privately; do not open public issues containing
exploits, credentials, raw prompts, private evidence, or personal data. Include
the affected version, impact, a minimal reproduction, and a safe contact
method. This repository is a testnet release candidate and must not process
production secrets or customer incidents.

Dadieng's core invariants are: local enforcement before unsafe execution; no
raw evidence onchain; deterministic release assertions; independent validator
threshold; explicit pending finality; signed short-lived manifests; and
immediate quarantine rollback after canonical confirmation.
